# SkyNotes

Handwriting notes for iPad (Apple Pencil), built as an installable web app.
Open in Safari on iPad, Share, Add to Home Screen.

- Pen (pressure), highlighter, stroke eraser, typed text, undo/redo
- Notebooks with lined/grid/dotted/blank paper, PDF export, JSON backup
- Offline first (IndexedDB + service worker); optional sync via Supabase (see supabase.sql)
